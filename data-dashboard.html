🔐 How Your Data Is Protected
Every time you describe a situation in the ER Case Navigator, this is what happens before any AI processing:
✓ All person names replaced with Role A, Role B, Role C
✓ Company names replaced with Company X
✓ Specific locations replaced with Location Y
✓ Anonymised text sent to Claude API — Anthropic never receives identifiable information
✓ Original narrative stored only in your personal Airtable record
✓ No data shared with third parties. Ever.

⚖️ Legal & Compliance
The Virorah Situation Room complies with India's Digital Personal Data Protection Act 2023 (DPDP Act). Key rights:
✓ Right to access your data — view all data held about you on this page
✓ Right to correction — update your MERIDIAN profile anytime via Edit Profile
✓ Right to erasure — delete all data instantly using the button above
✓ Right to portability — export all your data in JSON format anytime
✓ Data minimisation — only what you explicitly provide is stored
