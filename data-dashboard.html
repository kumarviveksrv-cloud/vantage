🔐 How Your Data Is Protected
Every time you write a case narrative, situation, or question into any AI-powered tool, this is what happens before any AI processing:
✓ Person names replaced with role-consistent placeholders (Manager A, Employee B)
✓ Company names replaced with Company X
✓ Specific locations replaced with Location A, Location B
✓ This step fails closed — if it can't complete safely, the request is blocked, never sent unredacted
✓ Original text stored only in your own account record
✓ No data shared with third parties beyond what's in our Privacy Policy

⚖️ Legal & Compliance
Virorah Vantage complies with India's Digital Personal Data Protection Act 2023 (DPDP Act). Key rights:
✓ Right to access your data — view all data held about you on this page
✓ Right to correction — update your MERIDIAN profile anytime via Edit Profile
✓ Right to erasure — request permanent deletion using the button above
✓ Right to portability — export all your data in JSON format anytime
✓ Data minimisation — only what you explicitly provide is stored
